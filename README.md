A round-based tactical first-person shooter in the browser, in the vein of the
classic team shooters but with its own map, art and names. Built with three.js as
static ES modules — no build step. It has enemy bots that navigate, take cover and
fight back; best-of-N rounds with teams; a between-round economy with money earned
per kill and per round and a buy menu of several weapons plus armour; a plantable
bomb objective with a timer; and shooting that rewards accuracy — spread that grows
with movement and fire, recoil, hitscan with damage falloff, and hitmarkers.

## Run it

```sh
node serve.ts
```
